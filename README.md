# Solaris — Light-Driven UI Playground

An experimental physical design system where UI components react to a movable light source.

## Features

- Draggable Sun / Moon controller
- Horizon-based day / night transition
- Dynamic sky, aurora and star blending
- Position-aware card lighting
- Magnetic hover interactions
- Fully viewport-based layout (no scroll)

## Tech

- React
- TypeScript
- Motion
- TailwindCSS
- CSS custom properties

## Interaction

Drag the orb above the horizon for day.
Pull it below for night.
Tap to toggle instantly.

---

Designed as a physical UI exploration.
